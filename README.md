# Nextmove

Run locally:

```sh
sf dev
```

Deploy:

```sh
sf publish
```

The starter app includes:

- `/`: a live todo list built with the platform kit (`@spacefast/zero/kit`).
- `/status`: a page that calls the capsule's `GET /api/status` endpoint.

`AGENTS.md` is the guide for coding agents working in this capsule.
